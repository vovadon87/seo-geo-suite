# Редакторские правила

Профиль сайта задаёт нишу, аудиторию, стиль и допустимые утверждения. Здесь — общие правила текстов.

## Стиль
Профессиональный, точный, естественный, предметный. Текст специалиста, а не рекламная листовка: конкретные параметры, причины, следствия. Для B2B: продукт и технология через задачу покупателя. Для B2C: простым языком, без жаргона. Для чувствительных тем (здоровье, финансы, право; режим «строгий» в профиле): только подтверждённые утверждения, экспертное авторство, оговорки, без обещаний результата.
Без канцелярита и без шаблонных нейросетевых оборотов (список — `anti-spam.md`).

## Структура
- Вступление 2–4 предложения: задача читателя и что он решит после прочтения. Без «в современном мире».
- Логичные H2, H3 при необходимости. Заголовки — о задаче или вопросе читателя, не склейка ключей.
- Прямые ответы (answer-first), таблицы сравнения там, где они короче текста.
- Проверяемые сведения (fact check) и обоснованные коммерческие аргументы.
- Естественный CTA из реальных действий сайта (форма, звонок, расчёт, образец и т. п. — по `site-context.md`).
- Блок внутри существующей страницы — без второго H1 (только H2/H3). Отдельная публикация — один H1.

## Запросы в тексте
Запросы определяют, какие вопросы раскрывает текст, а не сколько раз повторить слова. Использовать основные формулировки, естественные словоформы и синонимы, тематические термины, вопросы пользователей, конкретные характеристики. Не добиваться точного вхождения каждого ключа, не склеивать заголовки из ключей, не управлять «плотностью».

## Semantic Coverage Matrix (после написания)
| Кластер | Частотность главной фразы (источник) | Интент | Раздел текста | Статус |
|---|---|---|---|---|
Статусы: раскрыт полностью / частично / не раскрыт / не подходит странице / нужна отдельная страница. Проверка по смыслу, не по вхождениям.

## Конверсия (ворота 10)
Для каждого текста ответить: что пользователь хочет заказать или решить; что мешает решению; какую информацию ищет; критерии выбора; какие аргументы подтверждены; какой CTA уместен. Только реальные действия сайта. Один-два CTA по смыслу раздела.

## Объём
Фиксированного объёма нет. Объём = минимум, достаточный для полного ответа: определяется интентом, числом содержательных кластеров, сложностью темы, имеющейся экспертизой, выдачей и тем, что уже есть на странице. Коммерческая страница — компактный экспертный блок; самостоятельная публикация — подробное раскрытие. Решение и обоснование — в ТЗ.

## Факты и числа
Сроки, тиражи, показатели, цены, гарантии — только со статусом ПВ/ОС из `site-context.md`; иначе `[ЗАПОЛНИТЬ: …]`. Вопросы покупателей берутся из поиска и обращений, а не придумываются.
