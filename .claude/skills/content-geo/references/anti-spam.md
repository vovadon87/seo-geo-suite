# Анти-спам и защита от переоптимизации

Ориентир — справка Яндекса о переоптимизации текстов (искать актуальную в справке Вебмастера). Механическая часть — `scripts/quality_checks.py`; ручная — по спискам ниже. Универсальных числовых порогов «тошноты» нет: решение по смыслу, скрипт лишь подсвечивает кандидатов.

## Что выявлять (ворота 7)
- Запросный спам: фразы ради вхождения, не ради смысла.
- Избыточное повторение главной фразы; повтор одинаковых определений.
- Переспам заголовков (ключ в каждом H2; заголовки из склеенных ключей).
- Неестественные словоформы («услуга Москва купить недорого»).
- Бессмысленные перечисления и «простыни» синонимов.
- Одна мысль в разных разделах; дублирующиеся абзацы.
- Текст ради объёма (абзац не проходит проверку полезности — удалить).
- Искусственные географические перечисления («в Москве, Казани, Новосибирске, …»).
- Скрытый контент; пустые информационные блоки; нерелевантный FAQ.

## Шаблонные обороты — удалять и не заменять такими же
«В современном мире…», «На сегодняшний день…», «Широкий спектр решений…», «Важную роль играет…», «Индивидуальный подход…», «Высокое качество по доступной цене…», «Наша компания предлагает…», «Стоит отметить…», «Не секрет, что…», «Давайте разберёмся…», «Ключевым аспектом является…», «Подводя итог…». Замена: конкретное утверждение с фактом либо удаление фразы.

## Контроль повторов
Проверять: повтор одних преимуществ в разных разделах; повтор главного ключа без нужды; одинаковые определения; дублирующиеся абзацы; несколько разделов с одним интентом. Найден переспам — переписать по смыслу (не «разбавить»), повторить проверку.

## Скрипт
`python scripts/quality_checks.py <файл.md> [--json]` — топ лемм, повторяющиеся n-граммы, слова в 3+ заголовках, шаблонные обороты, похожие абзацы, географические перечисления. Это сигналы для редактора, не вердикт.
