# Перелинковка и защита от каннибализации

## Карта соответствия (до написания, ворота 9)
Для каждого кластера назначить один основной URL: **кластер → целевая страница → поддерживающие материалы → внутренние ссылки**. Актуальный список страниц — sitemap и раздел «Страницы» в `site-context.md`.
Различать роли страниц: общие страницы продукта · коммерческие страницы вариантов · отраслевые страницы · страницы услуг и условий · экспертные статьи. Известные пересечения записаны в реестре противоречий профиля; новые тексты не должны их углублять.

## Правила против каннибализации
- Один интент — один основной URL. Текст по кластеру, закреплённому за другой страницей, не создаётся; вместо него ссылка.
- Не создавать почти одинаковые страницы под перестановки ключей и искусственные региональные дубли («город × товар × вариант» без отдельного спроса и локального содержания).
- Новая страница только при отдельном намерении, самостоятельной ценности и ≥60 % уникального содержания.
- Перед публикацией сверить H1, title и главные фразы нового текста с существующими страницами; пересечение главных фраз = доработка.

## Требования к каждой внутренней ссылке
URL (существование проверено запросом или по sitemap; ссылки не выдумывать) · анкор (естественный, не ключ-склейка) · причина (какую задачу читателя закрывает переход) · рекомендуемое место в тексте · релевантный интент.

## Выход
Таблица пересечений (фраза/кластер → наш текст → конкурирующий URL сайта → риск → решение) и список рекомендованных ссылок с полями выше.
