# Information Gain: чем текст лучше существующего

## Сравнение до написания
Таблица из трёх колонок: **уже раскрыто на нашей странице → раскрыто у конкурентов → какую новую подтверждённую информацию добавляем**. Третья колонка — суть текста; пустая третья колонка = текст не писать.

## Типовые источники добавленной ценности (подбирать под нишу по профилю)
- Таблицы «вариант × условие» с выводами (что подходит когда, чего избегать).
- Практические критерии выбора и типичные ошибки заказчика с последствиями.
- Данные, нужные исполнителю для расчёта: чек-лист для клиента.
- Ограничения и случаи, когда решение не нужно.
- Подтверждённые примеры задач с параметрами (только статус ПВ).
- Собственные данные компании: сроки, этапы, регламенты, фото, реквизиты.
- Свежие и проверяемые факты (законы, стандарты, цены с датой) со ссылкой на источник.

## Если прироста ценности нет
Текст не создаётся автоматически. Вместо него предложить (на выбор владельца):
1. Улучшить существующий блок страницы.
2. Расширить FAQ: вопрос и самодостаточный ответ.
3. Добавить внутреннюю ссылку с релевантным анкором.
4. Взять отдельную тему с новым интентом (режим `cluster`).
5. Собрать недостающие экспертные данные у владельца (список вопросов).

## Проверка (ворота 5)
В итоговом отчёте перечислить конкретные элементы текста, которых нет у проанализированных конкурентов и на текущей странице, каждый с источником факта.
