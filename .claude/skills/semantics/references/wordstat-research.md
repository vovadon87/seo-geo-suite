# Wordstat: источники, операторы, частотность

## Главное правило
Частотность Wordstat не выдумывается. У каждого числа в ядре есть: **источник** (инструмент/файл), **дата замера**, **регион**, **тип замера** (без операторов / "в кавычках" / !словоформа). Число без этих полей в отчёты не попадает. Нет данных — «нет данных»; ниже порога инструмента ≠ ноль; не запрашивали — «не измерялось».

## Источники (по приоритету)
1. **Выгрузки владельца** (XLSX/CSV/TXT). Читать `scripts/wordstat_io.py`, исходный файл не изменять.
2. **Инструменты Wordstat в сессии**, если подключены: `wordstat_suggest` (топ запросов и частотность), `wordstat_dynamics` (динамика; работает только оператор `+`), `wordstat_regions` (региональный срез), `wordstat_cluster`. Имя инструмента записывать в колонку «Источник числа».
3. **Прежние файлы ядра** в рабочей папке. Данные старше 90 дней помечать «устарело».
4. **Яндекс Вебмастер «Запросы» и GSC** — фактические показы вашего сайта. **Не смешивать с частотностью**: это разные величины. В таблицах отдельные колонки с подписью источника.
5. **Подсказки поисковиков, GSC** — только для расширения списка фраз, не для частотности.

Без доступа ни к одному источнику: список гипотез, файл «на дозамер» (`templates/semantic-core.csv`, частотность пустая), результат помечается «семантика предварительная, частотность не подтверждена».
Не обходить CAPTCHA, авторизацию и ограничения источников.

## Операторы (сверять с актуальной справкой Яндекса)
| Оператор | Что фиксирует | Пример |
|---|---|---|
| без операторов | широкое соответствие: фраза + любые добавки, словоформы, порядок | `ремонт квартир` |
| `"фраза"` | только это число слов; словоформы и порядок свободные | `"ремонт квартир"` |
| `!слово` | точная словоформа; добавки допускаются | `!ремонт !квартир` |
| `+слово` | учитывать стоп-слово/предлог | `ремонт +в квартире` |
| `-слово` | исключить | `ремонт -телефонов` |
| `[фраза]` | фиксированный порядок слов | `[ремонт квартир]` |
«В кавычках» и «с !» — разные замеры, в ядре отдельные колонки. В динамике Wordstat работает только `+`.

## Регионы
Регионы замера берутся из профиля сайта (`profile.md`, раздел «Регион»): страна целиком и подтверждённые регионы продаж. Регион каждого замера пишется в строке данных, не в шапке файла. Региональные страницы обосновываются только региональным срезом.

## Расширение семантики
Проходы до исчерпания, не до заранее выбранного числа: синонимы продукта; виды продукта; варианты, материалы, комплектации; отрасли и задачи покупателя; условия применения; вопросительные формулировки; цена, срок, тираж, объём; регион. Остановка, когда новые проходы перестают давать связанные запросы. В отчёте фиксировать: это предел источника, а не полный охват рынка.

## Динамика и сезонность
При доступной истории (24 месяца): тренд год к году, пики, растущие подгруппы, сравнение регионов. Суммарный спрос **не** считается сложением вложенных фраз: широкие частотности пересекаются; в таблицах с суммами — оговорка.

## Колонки ядра (канонический формат)
Исходная фраза · Частотность без операторов · Частотность "в кавычках" · Частотность !словоформ · Регион · Период/дата замера · Интент · Кластер · Целевой URL · Коммерческая релевантность · Приоритет · Статус использования · Источник числа.
Проверка и дедупликация — `scripts/wordstat_io.py` (`validate`, `dedupe`, `export`).
