# seo-geo-suite

Набор навыков и агентов для Claude, который помогает продвигать сайт в поиске (Яндекс, Google) и в ответах нейросетей. Подходит для любого сайта и любой ниши: ничего не привязано к конкретной компании.

## Для чего он нужен

Вы пишете Claude обычным языком: «проверь сайт», «собери семантику», «напиши текст для страницы», «сделай отчёт за месяц». Набор сам выбирает нужный инструмент, проверяет сайт по фактам и выдаёт список проблем с приоритетами: что исправить сначала, почему это важно и как проверить результат.

Набор ничего не меняет на сайте сам и не обещает рост позиций. Он находит проблемы, готовит правки и честно пишет, что не удалось проверить.

## Из чего состоит

Папка `.claude/skills/` — навыки:

| Навык | Что делает |
|---|---|
| `seo-geo` | Главный: понимает задачу, заводит профиль нового сайта, передаёт работу нужному навыку, собирает полный аудит |
| `tech-audit` | Технический аудит: доступность сайта, редиректы, robots и sitemap, дубли, заголовки, разметка, доступ для ИИ-ботов, сравнение страницы до и после JavaScript |
| `speed-audit` | Скорость: вес страницы, Core Web Vitals, картинки, сторонние скрипты |
| `semantics` | Поисковые запросы: сбор, группировка по смыслу, карта «запрос → страница» |
| `content-geo` | Тексты и страницы для поиска и для ответов нейросетей, проверка фактов и качества |
| `local-seo` | Региональное SEO: адреса, телефоны, единые данные о компании на сайте и в картах |
| `seo-report` | Отчёт за период: сравнение месяцев по выгрузкам Вебмастера и Search Console, задачи на следующий период |
| `_shared` | Общие правила: приоритеты P0–P3, формат находки, обязательный раздел «что не проверено» |

Папка `.claude/agents/` — помощники, которые работают параллельно:

- `seo-tech-auditor` — технический аудит;
- `seo-speed-auditor` — аудит скорости;
- `seo-content-auditor` — аудит содержания страниц;
- `seo-geo-writer` — пишет тексты по правилам набора.

Остальное: `evals/` — 36 сценариев для проверки работы набора, `sites/` — сюда складываются профили ваших сайтов.

## Как это работает

1. Вы называете сайт и задачу. Если сайт новый, набор изучает нишу и создаёт его профиль, а спорные факты выносит в вопросы вам.
2. Скрипты на Python (только стандартная библиотека, для проверки JavaScript нужен Playwright) проверяют сайт и собирают данные.
3. Claude разбирает результат, отбрасывает ложные срабатывания и пишет отчёт.
4. При запросе «полный аудит» три агента-аудитора работают одновременно, а их находки объединяются в один список без повторов.

## Установка

Скопируйте папки `.claude/skills` и `.claude/agents` в `~/.claude/` (для всех проектов) или оставьте в репозитории (для одного проекта). Python 3.9+. Скрипты запускаются из своих папок `scripts/`.

## Что проверено, а что нет

Проверено: тесты скриптов проходят; технический обход, проверка скорости и объединение находок отработали на живом сайте.

Не проверено: выгрузка из Search Console и Вебмастера по API (нужны ваши токены, тесты шли на имитации), данные PSI и CrUX (нужны ключи), работа агентов на разных сайтах. Группировка запросов и определение интента — черновик для проверки человеком. Проверка JavaScript из облака не показывает регион и статус индексации.
